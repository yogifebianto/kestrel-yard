KESTREL YARD is a round-based tactical first-person shooter in the browser: two teams, short rounds won by eliminating the other side or by planting and detonating a bomb, money between rounds to buy weapons, and gunfire where stopping to aim beats spraying. Everything is drawn with three.js from code: no textures, no models, no audio files.

## Run it

```sh
node serve.ts --port 8080
```

Then open http://localhost:8080 in desktop Chrome.
